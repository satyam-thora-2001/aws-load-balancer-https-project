# 🚀 AWS Load Balancer HTTPS Project

## 📌 Overview

This project demonstrates a highly available and secure AWS architecture using Application Load Balancer with HTTPS enabled using a custom domain.

## 🧱 Architecture

- EC2 Instances (Apache Web Server)
- Application Load Balancer (ALB)
- Route 53 DNS Configuration
- AWS Certificate Manager (ACM SSL)
- HTTPS Listener Configuration

## ⚙️ AWS Services Used

- Amazon EC2
- Application Load Balancer (ALB)
- AWS Certificate Manager (ACM)
- Amazon Route 53
- Security Groups

## 🔐 Security

- HTTPS Enabled Website
- SSL/TLS Certificate using ACM
- Secure Load Balancer Listener (443)
- Restricted Security Group Rules

## 📈 Features

- Load Balancing
- HTTPS Secure Website
- Custom Domain Integration
- Health Checks
- High Availability
